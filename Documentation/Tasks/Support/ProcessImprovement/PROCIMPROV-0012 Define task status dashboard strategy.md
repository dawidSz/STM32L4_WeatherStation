# Define task status dashboard strategy

## Scope

Define how the current status of tasks is presented in dashboards.

- [ ] Identify the audiences and their questions (Chief Engineer, orchestrator, agents)
- [ ] Define the dashboard views (e.g. per task type, per status, per assignee, per concept)
- [ ] Choose the technology (e.g. Obsidian Bases) and the location of dashboard files
- [ ] Define which YAML fields the dashboards rely on and whether task fields need changes
- [ ] Describe the strategy in the process documentation
