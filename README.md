# STM32L4 Weather Station

Embedded firmware project for an STM32L4 microcontroller, developed with an agent-based engineering workflow.

## Repository layout

| Path | Content |
|------|---------|
| `CLAUDE.md` | Project rules for Claude Code (read at the start of every session) |
| `.claude/agents/` | Thin agent definitions loaded by Claude Code; each points to a full profile in `documentation/Agents/` |
| `documentation/` | Obsidian vault: process, agents, requirements, architecture, tasks, verification |
| `SW/` | Software project: STM32CubeMX configuration (`.ioc`), source code, build files |

## Documentation vault

Open `documentation/` as a vault in Obsidian. See `documentation/Home.md` for the entry point.
