# STM32L4 Weather Station

Embedded firmware project for an STM32L4 microcontroller, developed with an agent-based engineering workflow.

## Repository layout

| Path | Content |
|------|---------|
| `Documentation/` | Obsidian vault: project process, tasks, architecture |
| `Claude/` | Separate Obsidian vault: rules for cooperation with Claude Code, `CLAUDE.md`, agent definitions (`.claude/agents/`) |
| `SW/` | Software project: STM32CubeMX configuration (`.ioc`), source code, build files |

## Documentation vault

Open `Documentation/` as a vault in Obsidian. The entry point is `Documentation/Process/Strategy.md`,
which describes the process and the documentation structure.
